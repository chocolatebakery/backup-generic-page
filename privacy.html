Política de privacidade

Esta integração utiliza o Rclone e a API do Google Drive para enviar, consultar e gerir ficheiros de cópias de segurança na conta Google autorizada pelo respetivo titular.

Os ficheiros de backup podem conter dados pessoais e empresariais. São transferidos diretamente do servidor onde o Rclone está instalado para a conta Google Drive configurada. Os dados permanecem nessa conta segundo as respetivas definições de armazenamento, permissões e retenção.

O acesso à conta Google é autorizado por OAuth. Os tokens de autenticação são guardados localmente na configuração do Rclone, não neste website. Esta página não recebe os ficheiros, tokens nem credenciais de acesso.

O Rclone utiliza o acesso ao Google Drive exclusivamente para as tarefas de backup configuradas pelo responsável, incluindo envio, consulta e eliminação de versões antigas segundo a política de retenção definida. Não vende os dados nem os utiliza para publicidade.

O titular da conta pode revogar o acesso nas definições de segurança da respetiva conta Google. Para pedidos relativos aos dados guardados, deverá contactar o responsável pela conta e pelos backups.

Este website está alojado no GitHub Pages, cuja infraestrutura pode tratar dados técnicos de acesso à página de acordo com as respetivas políticas.
